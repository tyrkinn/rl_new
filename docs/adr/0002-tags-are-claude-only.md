# ADR-0002: Tags are Claude-generated and not user-editable

**Status:** Accepted

## Context

Tags are short keywords attached to an Entry during Enrichment. The question was whether users should be able to add, edit, or delete tags manually — as is common in bookmarking tools like Pinboard or Raindrop.

## Decision

Tags are exclusively generated by Claude during Enrichment. Users cannot add, edit, or delete them. Manual organization is handled through Folders, which users create and manage freely.

## Consequences

- Tag vocabulary is consistent and domain-aware: Claude generates tags using the context of the full article, not the user's memory of what they called something last time
- Synonym Aggregation can trust that tags come from a controlled, Claude-generated source — no user typos or inconsistent naming to reconcile
- Search quality improves over time as the synonym dictionary is built from clean tag data
- Trade-off: users who want fine-grained manual tagging are directed to Folders instead. Accepted because the AI-curated tag system is a core product differentiator vs. Pocket/Instapaper where tagging is manual and therefore often abandoned.

**The alternative** — allowing user tags alongside Claude tags — was rejected to avoid polluting the Synonym Aggregation input with inconsistent user-generated vocabulary.
